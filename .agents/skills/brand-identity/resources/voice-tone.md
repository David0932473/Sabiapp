# Copywriting: Voice & Tone Guidelines

## Brand Personality
- Direct and confident
- Student-focused, empathetic
- Smart but accessible — no unnecessary jargon
- Achievement-oriented

## Grammar & Mechanics
- **Headings:** Use ALL CAPS or Title Case for main headings. Sentence case for subheadings.
- **Punctuation:** Avoid exclamation points in standard UI copy. Use periods for complete sentences.
- **Clarity:** Active voice. Keep sentences concise.
- **No emojis** in UI copy. Use SVG icons instead.

## Terminology Guide

| Do Not Use | Use Instead |
|:---|:---|
| "Utilize" | "Use" |
| "In order to..." | "To..." |
| "Sabi AI Mentor" | "Sabi AI" or "Copilot" |
| "Timetable Cockpit" | "Study Calendar" |
| Emoji in UI | SVG icon |
